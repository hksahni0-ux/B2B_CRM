# B2B Growth Expo CRM

A CRM system for managing exhibitor and customer leads at B2B trade expos, refactored from a legacy PHP system to a modern Node.js/Express architecture.

## What it does

- Customer registration, login, and profile management (with photo upload)
- Role-based access for customers, staff, and admins
- Staff dashboard for lead tracking and qualification
- Admin panel for user and campaign oversight
- Webhook integration for automated lead capture
- Email pipeline integration (IMAP) for tracking customer correspondence

## Stack

Node.js · Express · PostgreSQL (Supabase) · bcrypt · express-session · vanilla JS/HTML/CSS frontend
